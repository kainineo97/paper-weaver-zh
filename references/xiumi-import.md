# 秀米导入与账号分流

本参考只在用户要求把文章带到秀米、测试秀米排版、或询问“普通账号 / VIP 账号有什么区别”时读取。它描述的是编辑器页面中的可选导入流程，不是公开发布或群发授权。

## 开始前的账号提示

如果用户没有说明账号类型，先用一句话询问：

> 这次要导入秀米吗？你的账号是普通账号、VIP，还是不确定？是否已经在秀米登录？

不要根据用户名、历史对话或网页未显示的状态猜测账号等级。用户只需说明等级或自行登录；不要索要密码、验证码或长期授权。

### 能力分流

| 账号状态 | 可走的路径 | 需要提前说明 |
|---|---|---|
| VIP | 在秀米编辑器中使用“更多 → 导入 HTML 代码”，上传本地 `dist/xiumi-import.html`，预览后导入并保存草稿 | 这是编辑器导入路径，不是公开发布；秀米仍会清洗不支持的 CSS，`data:image/...` 图片源可能被清空 |
| 普通账号（未显示 VIP） | 复制富文本到秀米、导入 Word/Markdown/公众号文章，或在秀米中手动插入图片和标题组件 | 不承诺能看到“导入 HTML 代码”入口；复杂的内联 CSS、图注和间距可能需要手动恢复 |
| 等级不确定 / 未登录 | 先生成并交付可复制的 HTML/阅读页，登录后再根据页面上实际可见的入口选择路径 | 不因入口缺失反复重试，也不要求用户交出登录信息 |

以上分流以当前页面实际可见状态为准，秀米产品权限可能变化。测试中观察到 VIP HTML 导入可保留紫色标题和灰色图注的内联样式，但不能把一次测试当成永久兼容承诺。

## 导入前的 HTML 准备

1. 在文章构建成功后保留原始 `dist/article.html`，另生成一份秀米专用副本，例如 `dist/xiumi-import.html`；不要改写原始阅读页。
2. 统一使用简单、内联的 CSS：正文字号、行高、对齐、段后间距；标题使用明确的 `color`、字号、字重、居中和边框；图注使用灰色、较小字号和居中。不要依赖外部样式表、脚本、伪元素或复杂布局。
3. 连续正文段落之间加入可见的空白策略（空段或段后间距）。秀米可能把空段转换为组件间距，因此要在预览中实际检查，而不是只数源文件节点。
4. 检查图片：`data:image/...` 内嵌图片在秀米导入时可能被清除。优先使用已上传到同一秀米账号的 `img.xiumi.us` 地址，或在秀米图库/图片上传入口逐张上传；不得凭空猜测图片 URL。记录图片总数、图注顺序和加载结果。
5. 文件名可包含文章编号、账号类型和日期，避免误把测试稿覆盖到旧稿；默认新建独立图文，不覆盖用户已有草稿。

## VIP 浏览器导入流程

仅当用户明确要求上传/导入，并且已登录、页面显示可用的 VIP/HTML 入口时执行：

1. 打开秀米新建或用户指定的草稿，确认标题和账号状态。
2. 通过“更多 → 导入 HTML 代码”打开导入面板，上传 `dist/xiumi-import.html`。
3. 在点击最终“导入”前检查预览：标题颜色/边框/居中、图注颜色/字号/居中、连续段落间距、图片数量与 `naturalWidth`。如果图片为空，先恢复为同一稿件已上传的秀米 URL 或完成图片上传，再继续。
4. 说明秀米可能清除部分 CSS；必要时把效果改成更简单的内联样式或秀米原生组件，不要把“预览保留”误报为“所有样式永久同步”。
5. 最终导入和保存会修改第三方草稿，必须在提交前获得用户确认。保存后重新读取标题、摘要、段落间距、标题/图注计算样式和图片加载状态，并记录秀米草稿 URL/ID。
6. 公开发布、同步到公众号、群发和覆盖旧稿均需另行明确授权；本流程默认只保存秀米草稿。

## 普通账号回退流程

普通账号或 VIP 入口不可用时，不要把 HTML 源码整段当作正文粘贴给用户。交付两种可用材料：

- 一份可复制富文本/阅读页，用于直接粘贴到秀米；
- 一份 Word 或 Markdown 导入版本（若用户选择该路径），并标注标题、图注、图片和段落间距可能需要在秀米中手动校正。

把“可以生成秀米兼容 HTML”与“普通账号可以直接导入 HTML”分开表述。若用户仍希望在普通账号中保持紫色标题和图注，可指导其在秀米中选中文本后使用颜色、字号、对齐和间距工具，或使用秀米原生标题/图片/图注组件逐段替换。

## 结果记录与失败边界

交付时至少记录：账号分流、采用的导入/回退路径、秀米是否实际保存、标题/图注样式是否保留、图片加载数/总数、段落间距是否经预览核对，以及任何被清洗的 CSS。若未登录、无 VIP 入口、文件选择器失败或图片无法恢复，交付本地源文件和具体阻塞点，不声称已完成秀米导入。

秀米公开的同步接口文档描述的是平台申请同步 app、绑定用户并接收 HTML/图片的服务端对接；它需要独立的接口注册、鉴权和服务器实现，不是本地浏览器自动化的替代品。参考：[秀米图文同步接口文档 2.0](https://ent.xiumi.us/)。
