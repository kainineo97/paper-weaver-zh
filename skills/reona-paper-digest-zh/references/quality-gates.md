# 交付前检查

## 内容与证据

- 所有关键数字都能定位到本地论文材料，并保留正确的条件、分子、分母和重复层级。
- 引用编号按首次出现顺序递增，正文编号与 `refs.md` 闭环。
- 论文直接报告的内容与文章延伸分析在版式上可区分。
- 标题、副标题、摘要和结语的判断强度不超过正文证据。

## 中文表达

- 开头提出的问题在结语中得到回应。
- 每段承担清楚的功能，没有同义反复或机械收束。
- 句子有明确主语和动作；长句中的因果、转折和限定关系清楚。
- 不使用空泛拔高、翻译腔连接词、连续排比或可预测的三段式总结。
- 术语、英文大小写、数字空格、引号和标点全篇一致。

## 页面同步

- `article.md` 和 `meta.yaml` 分别是正文与文章头信息的唯一来源。
- 先由 ReoNa `render.py` 生成最终 `dist/article.html`，再由 `build_synced_views.py --screenshot` 同时生成两页和与之对应的 `dist/preview.png`。
- `reading.html` 与 `preview.html` 都包含一个 `#wechat-content`；其 `data-content-sha256` 相同，内部 HTML 逐字节一致。
- 微信预览的复制按钮读取 `#wechat-content`，不读取旧的隐藏正文、缓存字符串或另一个文件。
- 两页都包含同一封面、栏目编号、主标题、副标题、正文图片、提示框、表格和参考文献。
- `preview.png` 来自同步后的 `preview.html`，不沿用 `render.py` 在同步前生成的正文截图。
- 在桌面和 390 px 手机宽度下无横向溢出，图片加载完整，表格可读。

## 发布边界

- 页面生成与本地复制预览不改变 `meta.yaml.status`。
- 只有发布脚本确认草稿保存成功后，状态才可改为 `draft`。
- 群发始终由用户人工完成。
