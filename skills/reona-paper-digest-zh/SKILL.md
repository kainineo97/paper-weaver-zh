# ReoNa 论文精读中文编辑

把 `reona-paper-digest` 的证据核对与公众号工具链，同 `humanizer-zh` 的中文母语化编辑合并为一条工作流。交付物应在科学内容、中文表达和页面内容三个层面保持一致。

## 上游能力

本 skill 依赖两个独立 skill，并保持它们为规则与脚本的单一来源。fork 布局下 ReoNa 位于仓库根，其他 skill 位于 `skills/`；独立安装时仍采用并列目录：

- fork 布局读取 `../../SKILL.md`；独立安装读取 `../ReoNa-paper-digest/SKILL.md`。确认该位置同时有 ReoNa 的 `scripts/ingest.py` 与 `scripts/render.py`，再采用其材料归档、证据核对、WeMD、图片、引用、封面、渲染和发布状态规则。需要具体操作时再读取它链接的相关 reference，并直接调用其 `scripts/`，不要复制脚本。
- 读取 `../humanizer-zh/SKILL.md`，采用其中立中文路径。深度改写时再读取 `../humanizer-zh/references/patterns.md`；科学文章默认不询问或套用作者声音，除非用户主动指定。

如果两者出现冲突，以科学证据准确、用户当前要求和本文件的页面同步规则为准。

## 单一来源与交付物

`article.md` 是正文唯一来源，`meta.yaml` 是标题、副标题、封面和状态的唯一来源。不要在生成后的 HTML 中手工改正文。

完成正文后生成：

- `dist/article.html`：由 ReoNa `render.py` 生成的微信内联样式正文片段。
- `dist/reading.html`：含封面、栏目编号、标题、副标题和完整正文的独立阅读页。
- `dist/preview.html`：与阅读页展示相同文章内容的微信富文本预览页；页面顶部按钮复制当前可见的完整文章内容，不复制按钮或阅读辅助控件。

阅读页与微信预览必须由同一次 `scripts/build_synced_views.py` 调用生成。两页的 `#wechat-content` 应逐字节相同；不要分别拼装标题或正文。正文改动后依次重新运行 `render.py` 与 `build_synced_views.py`。

## 工作流

1. **加载本篇材料。** 读取专栏的编辑日历、文章摘要、品牌文风，以及当前文章的 PDF、讨论记录、引用和元数据。只把本地材料当作论文事实来源；讨论用于恢复追问链和待核对问题。
2. **建立证据表。** 对关键数字记录研究对象、条件、分子、分母、重复层级、图表位置和证据强度。区分论文作者的结论、文章编辑者的推论与尚未验证的问题。
3. **按问题链写作。** 先说明论文解决什么问题，再依次解释方法、结果、验证和边界。小节标题使用克制的陈述句。正文不放一级标题，主标题来自 `meta.yaml`。
4. **完成中文编辑。** 先修正主线和段落功能，再处理句法、术语和节奏。为每个动作写明主体；用具体实验或比较对象代替空泛的“结果表明”“证据说明”。谈论文时优先写“这项研究”“论文”“作者”或“研究团队”，避免让“本研究”看起来像文章作者在报告自己的实验。
5. **分开事实与延伸分析。** 论文报告的方法、数据和作者结论放在普通正文。由实验设计、统计口径或结果缺口推导出的判断，集中写入 `> [!NOTE]`，标题以“延伸讨论｜”开头。整节都是领域外推时，在标题中标明“延伸讨论”，并用 `> [!IMPORTANT]` 说明它不是论文直接提出的标准。提示框数量由内容决定，不为排版整齐而硬凑。
6. **用贡献与边界收尾。** 结语回应开头的问题，分别概括论文推进了什么、现有证据不能支持什么、下一步需要哪类验证。避免口号和泛化意义。
7. **渲染并同步页面。** 先运行 ReoNa `publish-check.py`，再用 `render.py` 生成 `article.html`，随后运行本 skill 的 `build_synced_views.py <article-dir> --screenshot`。该命令同时生成两页并更新 `preview.png`。修改正文后不得只重建其中一个页面。
8. **验证成品。** 在桌面与约 390 px 手机宽度检查两页。核对标题、副标题、封面、小节、提示框、表格、图片和参考文献；确认无横向溢出。执行脚本的 `--verify-only`，确认两页共用同一份内容。实际粘贴或上传微信公众号仍需遵守用户授权。

## 科学写作边界

- 严格区分“未报告”“未评估”“未检测到”“差异无统计学意义”和“实验未能产生结果”。
- 阳性细胞比例、每个起始细胞的分化产率、每个成熟细胞的产板量和单位体积产量不可混用。
- 单细胞数量不是生物学重复数；训练集表现、内部测试、参与模型选择的外部数据和独立验证集应分别描述。
- 标志基因、结构成熟、实际功能和产物质量需要不同证据，不因相关方向一致就改写成因果关系。
- 保留论文未解决的不确定性，不补写实验参数、机制或临床结论。

详细检查项见 [references/quality-gates.md](references/quality-gates.md)。

## 交付

向用户提供 `reading.html` 作为完整审阅页，提供 `preview.html` 作为微信富文本复制页，并明确两页文章内容相同。报告发布前检查、页面同步检查和移动端检查结果。除非用户明确要求，不上传或群发。
