# Note Organizing Skill

`note-organizing` 是一个中文笔记整理 skill，用于把原文、转写稿、访谈、播客、会议记录、课堂材料或零散资料，整理成清楚、忠实、可复习、可沉淀的 Markdown 笔记。

它不是文章成稿工具，也不是公众号写作工具。它的重点是还原材料逻辑、清理噪音、提炼主题、合并相近观点、保留关键细节和原文依据。

## Skill 定位

`note-organizing` 解决的是“材料太散，需要整理成可复用知识笔记”的问题。

它默认输出主题合并型笔记，而不是普通摘要。整理时会先识别材料中的全部主题，再合并重复、相近、前后呼应的内容，最后按大主题输出结构化笔记。

## 适用场景

- 整理课堂笔记
- 整理讲座转写稿
- 整理会议记录
- 整理访谈、播客、录音转写
- 整理文章和资料
- 把文件夹中的多份材料合并成一份综合笔记
- 把杂乱文本清洗成可读 Markdown
- 为后续写文章、做知识库或复习沉淀材料

## 不适用场景

- 写公众号文章
- 写成能发布的完整文章
- 写人人都是产品经理风格文章
- 写有传播感、标题冲突和开篇钩子的文章
- 写 PRD 或技术文档
- 只需要几句话极短摘要

如果目标是写成文章，应使用 `article-writing`。如果目标是给 Claude Code / Codex 生成开发 PRD，应使用 `vibe-coding-prd`。

## 核心输出结构

默认结构：

```markdown
# 标题

## 一、主题标题

### 核心要点
- 要点一：……
- 要点二：……
- 要点三：……

### 展开阐述
基于原材料，把这个主题背后的逻辑、关系、原因、例子讲清楚。语言可以修顺，但不要加入原材料没有的判断。

### 原文引用与说明
> “……”

说明：这句话是本节主题的核心依据，说明了……
```

## 处理原则

- 忠实优先，不编造原文没有的信息
- 先识别全部主题，再合并语义相近主题
- 相同观点不要拆成多个章节重复写
- 保留关键案例、概念、步骤、论证链和原文金句
- 清理时间戳、重复句、无意义口头语和明显转写噪音
- 引用少而准，并说明引用支撑了什么主题
- 格式紧凑，避免整篇堆空行
- 默认中文 Markdown

## 文件说明

- `SKILL.md`：Hermes Agent Skill 主文件
- `README.md`：当前 skill 的说明文档

## 使用方式

在支持 Hermes Skill 的环境中加载：

```text
skills/note-organizing/SKILL.md
```

也可以直接将 `SKILL.md` 作为笔记整理 Agent 的上下文提示词使用。

典型使用方式：

```text
请使用 note-organizing skill，把下面的讲座转写稿整理成一份中文 Markdown 笔记。
要求：先合并相近主题，再按主题输出核心要点、展开阐述和原文引用说明。不要写成公众号文章。
```

如果用户给的是同一课程、同一天或同一主题下的多个转写文件，并要求“整理笔记”而不是“每个文件分别整理”，默认合并成一份综合课程笔记。

## 验证清单

使用该 skill 整理完成后，至少检查：

- 是否判断清楚输出类型：主题合并型笔记、整理文章样稿或清洗型笔记
- 是否没有误写成公众号成稿
- 是否忠实原文，没有编造材料外信息
- 是否已清理明显噪音、时间戳、重复句和无意义口头语
- 是否先识别全部主题，再合并语义相近主题
- 相同观点是否没有被拆成多个章节重复铺开
- 是否保留关键案例、概念、步骤、论证链和原文金句
- 引用是否少而准，并且有解释说明
- Markdown 层级是否清晰，整体格式是否紧凑
